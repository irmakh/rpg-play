# UX improvement plan — 2026-11-16

Scope chosen by the user: faster combat, phone player view, status + undo, DM navigation
(with onboarding/empty states and one preferences panel). Players use mixed devices
(phones, tablets, laptops), and DM and player pain are weighted equally, so releases
alternate between the two sides. This is a plan only; no code yet.

## Method

1. **Heuristic review** of each screen in a release against Nielsen's 10 usability
   heuristics before building, to confirm the problem is real and catch nearby issues.
2. **Rank by impact × frequency ÷ effort.** Things done every round of combat beat things
   done once per campaign.
3. **Small releases**, one theme each, tested locally by the user before the next.
4. **Reuse before building**: one shared component per pattern (toast, status light,
   palette) loaded by every page, the way `js/lib/realtime.js` and `notifications.js`
   already work.
5. **Responsive, not separate**: one layout that adapts at the existing 760px breakpoint,
   with a 44×44px minimum touch target (Apple HIG / WCAG 2.5.8) on touch screens.

## What already exists (don't rebuild)

- Character sheet autosave already shows "Saving… / Saved!" (`#save-status`, index-char.js).
- Table HP panel already has damage/heal modes with an amount box and quick buttons
  (`applyHpChange`, `setHpAmount`, bulk quick damage/heal).
- Short/Long Rest already refills slots, limited uses and item charges (`actionRest`).
- Single-level undo exists for token moves and prepare-map deletes.
- Two separate `showToast` functions exist (index-dice.js, table-utils.js) — to be unified.
- Realtime reconnects silently every 3s; the user is never told it dropped.
- Initiative **Next/Prev are visible to every player** while combat runs, so any player can
  advance anyone's turn.
- Only `handouts.html` and `stories.html` link back to the DM hub; the other DM pages are
  dead ends without the browser's Back button.

## Suggested order

1 → 2 → 3 → 4. Release 1 first because toasts and the connection light are used by every
later release. 2 (shared) and 3 (players) come before 4 (DM tools) since combat happens
every session.

## Decisions (made by the user 2026-11-16)

1. **Undo window: 15 seconds**, and the DM can undo anything, including a player's give.
2. **Prev turn: DM only.** Players get End turn on their own turn and nothing else.
3. **Condition durations: ask at each turn.** When a token with a timed condition starts
   its turn, its controller (the player for their character, the DM for monsters; the DM
   can answer for anyone) is asked per condition: **Decrease now**, **Decrease at end of
   turn**, or **Disregard** (leave the count unchanged this turn). This replaces the
   automatic tick in 2.4.
4. **Concentration: a button the player presses** ("Roll CON save"), plus "Drop
   concentration".
5. **Ctrl+K: DM and players in Release 4.** Players' results are limited to what they can
   already see (their own sheet, spells, items, shared handouts, player pages).
6. **Preferences: per device** (browser storage), so a phone and a laptop can differ.
